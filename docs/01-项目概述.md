# Schemagine 项目概述

Schema-driven 动态表单与数据管理引擎。基于 Vue 3 Composition API + Element Plus + vxe-table 构建，支持通过 JSON Schema 配置动态渲染列表、卡片、新增三种视图。

## 技术栈

| 层 | 技术 |
|---|------|
| 框架 | Vue 3.5 (Composition API + `<script setup>`) + TypeScript 6 |
| 构建 | Vite 8 |
| 状态管理 | instanceState 工厂（provide/inject，主链路）+ Pinia 3（候选值/公式缓存） |
| UI 组件 | Element Plus 2.13 |
| 表格 | vxe-table 4.18 + vxe-pc-ui 4.13 |
| 路由 | vue-router 5 |
| 公式引擎 | mathjs 15 |
| 工具函数 | xe-utils 4 |
| 测试 | Vitest 4（单元测试）+ Playwright 1.59（E2E） |
| Lint | ESLint 10 + oxlint 1.60 |
| 格式化 | oxfmt 0.45 |
| 包管理 | pnpm（workspace） |

## 架构分层

```
SchemaEngine (入口)                 ← 加载 Schema、权限、用户配置，编排全局流程
  └─ SchemaContextProvider          ← provide 上下文 (schema/records/viewMode/...)
       └─ ViewContainer             ← 布局容器，根据 viewMode 切换子视图
            ├─ ListView             ← 列表视图（表格模式）
            │    ├─ SchemaFilterBar  ← 筛选栏（8种算子）
            │    ├─ ListActionBar   ← 列表级操作按钮
            │    ├─ SchemaTable     ← vxe-table 表格
            │    ├─ SchemaPagination← 分页器
            │    └─ BottomTabs      ← 底部快速筛选标签
            ├─ CardView             ← 卡片浏览视图（上/下条导航）
            │    └─ SchemaCard      ← 单卡片渲染（16列Grid布局）
            └─ CreateView / CardCreateView ← 新增视图（批量/单卡片录入）
```

**数据流方向**：`UI → Store/Composables → Service/Mock`（严格单向，禁止子组件直接改写全局状态）

## 三种视图模式

| 视图 | 组件 | 说明 |
|------|------|------|
| 列表视图 (list) | ListView + SchemaTable | vxe-table 表格展示，支持排序、筛选、列设置；编辑交互由 `schema.listEditMode` 控制（双击行内编辑 / 选中后点击“编辑”跳转卡片） |
| 卡片视图 (card) | CardView + SchemaCard | 卡片浏览，上/下条导航，行内编辑，16列 Grid 布局 |
| 新增视图 (create) | CreateView / CardCreateView | 批量新增（列表式）或单卡片录入，公式自动计算，列锁定 |

## 路由

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | - | 重定向到 `/voucher` |
| `/{module}` | ModuleDemo | 快捷模块路由（voucher/ap/invoice/sales-order/receivable/user/workshop/empty/no-perm） |
| `/module/:moduleId` | ModuleDemo | 通用模块路由 |
| `/editor` | SchemaEditor | Schema 可视化编辑器 |

## 筛选语法

详见 [26-筛选语法使用说明](../.trae/documents/schema-dev-plan/26-筛选语法使用说明.md)。核心采用 `FilterClause[]` 协议，支持 10 种算子：`eq` / `neq` / `like` / `notLike` / `in` / `notIn` / `between` / `notBetween` / `isNull` / `isNotNull`。

## 错误处理

- API 层统一返回 `ApiResponse<T>` 格式
- 错误码见 `constants/index.ts` 的 `ERROR_MESSAGES`
- 模块加载失败时显示重试按钮
- 权限不足时显示无权限提示
- 版本冲突弹出确认对话框
