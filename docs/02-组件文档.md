# 组件文档

## 1. 表格组件

### 1.1 VxeTableWrapper

**文件**: `src/components/table/VxeTableWrapper.vue`

隔离第三方 vxe-table 库，输出项目需要的标准表格事件。实现表头筛选/排序弹层、单元格编辑模式、FK下拉搜索、关联字段点击、列拖拽排序。

**Props**:

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `moduleId` | `string` | - | 当前模块 ID（用于表头内容筛选请求候选值） |
| `data` | `Record<string, unknown>[]` | - | 表格行数据 |
| `columns` | `WrapperColumn[]` | - | 列定义 |
| `loading` | `boolean` | `false` | 加载状态 |
| `height` | `string \| number` | - | 表格高度 |
| `maxHeight` | `string \| number` | - | 最大高度 |
| `virtualScroll` | `boolean` | `false` | 虚拟滚动 |
| `editable` | `boolean` | `false` | 可编辑模式 |
| `selectedRowId` | `string \| null` | `null` | 选中行 ID（用于整行高亮） |
| `sortConfig` | `{ field?, order? }` | - | 当前排序状态 |
| `rowKey` | `string` | `'_recordId'` | 行唯一键名 |
| `columnDraggable` | `boolean` | `false` | 列可拖拽排序 |
| `fixedRowCount` | `number` | `undefined` | 固定行数模式 |
| `filterClauses` | `FilterClause[]` | - | 当前筛选条件（用于高亮/内容筛选联动） |

**WrapperColumn 类型**:

| 字段 | 类型 | 说明 |
|------|------|------|
| `field` | `string` | 字段标识 |
| `title` | `string` | 列标题 |
| `width` | `number` | 列宽 |
| `fixed` | `'left' \| 'right'` | 列固定 |
| `sortable` | `boolean` | 可排序 |
| `visible` | `boolean` | 可见性 |
| `align` | `'left' \| 'center' \| 'right'` | 对齐方式 |
| `formatter` | `(params) => string` | 格式化函数 |
| `isAction` | `boolean` | 是否操作列 |
| `isRelation` | `boolean` | 是否关联列 |
| `cellClass` | `(params) => string` | 单元格CSS类 |
| `fieldType` | `string` | 字段类型 |
| `targetModule` | `string` | FK目标模块 |
| `selectOptions` | `Array` | 下拉选项 |
| `trueLabel` / `falseLabel` | `string` | 布尔字段标签 |

**Events**:

| 事件 | 载荷 | 说明 |
|------|------|------|
| `sort-change` | `{ field, order }` | 排序变化 |
| `filter-change` | `{ field, clause }` | 表头内容筛选变化（确认后才触发；`clause=null` 表示清除该字段筛选） |
| `row-click` | `{ row, rowIndex }` | 单击行（用于行选择） |
| `cell-click` | `{ row, column, rowIndex, colIndex }` | 单击单元格 |
| `cell-dblclick` | `{ row, column, rowIndex }` | 双击单元格（FK触发快速创建） |
| `edit-activated` | `{ row, column, rowIndex }` | 编辑激活 |
| `edit-closed` | `{ row, column, value }` | 编辑关闭 |
| `inline-edit` | `{ row, field, value, oldValue }` | 行内编辑确认 |
| `column-drag-end` | `{ columns, newOrder }` | 列拖拽完成 |
| `row-action` | `{ row, actionId }` | 行操作点击 |
| `relation-click` | `{ row, column }` | 关联字段点击 |

**高度自适应机制**:

- 默认模式：外层 `flex:1; min-height:0`，`ResizeObserver` 监听包裹层高度传给 vxe-table
- 固定行数模式：`height = HEADER_HEIGHT(49) + fixedRowCount × ROW_HEIGHT(44) + BORDER_HEIGHT(1)`

**单元格编辑模式**: 支持 text/number/date/boolean/select/fk 类型；FK 字段编辑时异步加载候选值列表并缓存。

**表头筛选/排序弹层**:
- 每列标题右侧提供箭头按钮，弹出层包含：`升序 / 降序 / 清除排序` + `内容筛选`
- 内容筛选为 Excel 风格：关键词过滤候选值、全选/部分选择、显示出现次数，点击“确定”后才会 `emit('filter-change')`
- 候选值来源：`recordService.listFieldValueCandidates({ moduleId, field, keyword, page, pageSize, filters })`

## 2. 卡片组件

### 2.1 SchemaCard

**文件**: `src/components/card/SchemaCard.vue`

单卡片渲染组件，采用 16 列 CSS Grid 布局。支持浏览/编辑两种状态。

**Props**:

| Prop | 类型 | 说明 |
|------|------|------|
| `fieldSchemas` | `FieldSchema[]` | 字段 Schema 数组 |
| `record` | `RecordEntity` | 当前记录 |

| `cardLayout` | `CardLayoutConfig \| null` | 卡片布局配置 |

**Events**:

| 事件 | 载荷 | 说明 |
|------|------|------|
| `field-change` | `{ field, value, oldValue }` | 字段变更 |
| `save` | `void` | 保存 |
| `cancel` | `void` | 取消编辑 |

**布局规则**:
- 默认短字段 span=8（一行2个），长字段（text/json/url/attachment/image）span=16（独占一行）

- 卡片头部显示记录 ID + 状态标签

`src/components/field/editors/ValueRenderer.vue` — 只读值渲染器，根据字段类型格式化显示（日期格式化、布尔标签、FK 名称查找、关联摘要等）。

## 4. 筛选组件

### 4.1 SchemaFilterBar

**文件**: `src/components/filter/SchemaFilterBar.vue`

根据 Schema 动态渲染筛选控件，输出标准化 `FilterClause[]`。

> 说明：当前列表视图的筛选入口已迁移为“表头箭头筛选/排序弹层”，SchemaFilterBar 作为通用筛选组件保留（适用于外部嵌入、独立筛选区域等场景）。

**Props**:

| Prop | 类型 | 说明 |
|------|------|------|
| `fields` | `FieldSchema[]` | 所有字段 Schema |
| `modelValue` | `FilterClause[]` | 当前筛选条件（v-model） |
| `infiniteScroll` | `boolean` | 无限滚动模式 |
| `showFilterStatus` | `boolean` | 是否显示筛选状态 |

**Events**:

| 事件 | 载荷 | 说明 |
|------|------|------|
| `update:modelValue` | `FilterClause[]` | 筛选条件变更 |
| `search` | `FilterClause[]` | 触发搜索（立即查询） |
| `reset` | `void` | 重置所有筛选 |
| `remove-filter` | `fieldKey` | 移除单个字段筛选 |

**支持的筛选类型**:

| 字段类型 | 控件 | 算子 | 排除版本 |
|----------|------|------|----------|
| text | 文本输入 + 模糊/精确切换 | like / eq | notLike / neq |
| select/multi-select | 下拉框 + ≠ 按钮 | eq | neq |
| date/datetime | 日期选择器 + 单日/范围切换 | eq / between | neq / notBetween |
| boolean | 下拉框 + ≠ 按钮 | eq | neq |
| fk | 多选搜索下拉 + collapse-tags | in | notIn |

额外支持 `isNull` / `isNotNull`（通过 `nullableFilter` 控制）和 `exclude` 排除按钮。

**交互特点**:
- 有激活筛选时字段区高亮蓝色背景
- 排除按钮激活后变红
- FK 多选支持异步搜索
- 每个字段筛选变更立即 `emit('search')`

#### 筛选运算符显示映射

**文件**: `src/utils/filterLabels.ts`

筛选标签中运算符的显示由 `OPERATOR_LABEL_MAP` 和 `getOperatorLabel()` 统一管理，SchemaFilterBar 和 ListView 筛选回退路径共用同一份映射。

**映射表**:

| 运算符 | 显示 |
|--------|------|
| `eq` | `=` |
| `neq` | `≠` |
| `like` | `包含` |
| `notLike` | `不包含` |
| `in` | `属于` |
| `notIn` | `不属于` |
| `between` | `介于` |
| `notBetween` | `不介于` |
| `isNull` | `为空` |
| `isNotNull` | `不为空` |

**公开 API**（`src/index.ts` 导出）:

```ts
import { OPERATOR_LABEL_MAP, getOperatorLabel } from 'schemagine'

// 直接访问映射
OPERATOR_LABEL_MAP['eq']  // '='

// 安全获取（未知 operator 回退原值）
getOperatorLabel('eq')     // '='
getOperatorLabel('like')   // '包含'
```

**使用位置**:

| 文件 | 用途 |
|------|------|
| `SchemaFilterBar.vue#buildFilterSummary` | 构建 FilterSummaryItem 时解析 `operatorLabel` |
| `ListView.vue#filterSummaryItems` | 回退路径 — 当 filterBarRef 不可用时（如 SSR），直接从 filters prop 构建摘要标签 |

> **修改注意**：新增算子时需同步更新 `FilterOperator` 类型定义（`src/types/service.ts`）和 `OPERATOR_LABEL_MAP`（`src/utils/filterLabels.ts`）。

### 4.2 BottomTabs

**文件**: `src/components/filter/BottomTabs.vue`

位于列表底部，展示可筛选 select 字段（如"状态"）的快速筛选标签。

在 ListView 中与 SchemaPagination 合并为同一行（`.list-footer`），tabs 区域可横向滚动。

**Props**:

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `tabs` | `FilterTab[]` | - | 标签列表 |
| `activeTabId` | `string` | - | 当前激活标签 ID |
| `showCount` | `boolean` | - | 是否显示 badge（有值时渲染） |
| `allowCustomize` | `boolean` | - | 是否允许自定义（增删标签） |

**Events**:

| 事件 | 载荷 | 说明 |
|------|------|------|
| `change` | `tabId: string` | 切换标签 |
| `add-tab` | `void` | 添加标签 |
| `edit-tab` | `tabId: string` | 编辑标签 |
| `delete-tab` | `tabId: string` | 删除标签 |

**FilterTab 类型**:

```ts
interface FilterTab {
  id: string
  label: string
  count?: number            // 客户端本地统计（向下兼容）
  badge?: string | number   // 灵活的 badge 内容（计数、合计、平均等）
  badgeLoading?: boolean    // 直接在 tab 数据上标记加载中
  filter?: FilterClause     // 点击该标签时应用的筛选条件
}
```

#### Badge 异步控制

badge 支持外部异步控制，适用于服务器端数据量大的场景（计数、合计、平均等）。

**Badge 显示优先级**: `setTabBadge 外部覆盖 > tab.badge 属性 > tab.count 本地统计`

**暴露方法**（通过 `defineExpose`）:

| 方法 | 签名 | 说明 |
|------|------|------|
| `setTabBadge` | `(tabId: string, value: string \| number) => void` | 设置单个 tab 的 badge |
| `setTabBadges` | `(records: Record<string, string \| number>) => void` | 批量设置（key=tabId, value=badge） |
| `clearBadges` | `() => void` | 清除所有外部 badge 覆盖 |
| `setTabBadgeLoading` | `(tabId: string, loading: boolean) => void` | 控制单个 tab 的加载动画 |
| `buildTabsFromField` | `(field, records) => FilterTab[]` | 从字段 + 记录生成标签（向下兼容） |
| `resolveTabFilter` | `(tabId) => FilterClause \| null` | 解析标签对应筛选条件 |

**使用示例**:

```ts
const bottomTabsRef = ref<InstanceType<typeof BottomTabs> | null>(null)

// 初次加载 Schema 时请求后端 badge 数据
async function loadBadges() {
  bottomTabsRef.value?.setTabBadgeLoading('__all__', true)
  const res = await api.getTabBadges({ moduleId: 'xxx' })
  if (res.success) {
    bottomTabsRef.value?.setTabBadges(res.data.badges)
    // res.data.badges 格式: { '__all__': 100, 'f:status:active': 42, ... }
  }
}

// 数据更新事件触发重新请求，标签切换不触发
function onDataUpdated() {
  loadBadges()
}
```

**交互要点**:
- 切换 tab 时不会自动触发 badge 更新，只有数据变更事件触发才重新请求
- loading 态显示旋转动画（`tab-badge-loading`），`tab-count-wrap` 有内容时才渲染
