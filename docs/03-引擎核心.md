# 引擎核心

## 1. SchemaEngine（入口）

**文件**: `src/engine/entry/SchemaEngine.vue`

引擎顶层入口组件。负责加载 Schema、初始化 Store、统一协调筛选/排序/分页/视图切换/弹窗。

**Props**:

| Prop | 类型 | 说明 |
|------|------|------|
| `moduleId` | `string` | 模块标识 |
| `initialViewMode?` | `ViewMode` | 初始视图模式 |
| `embedded?` | `boolean` | 嵌入模式（带边框） |
| `readonly?` | `boolean` | 只读模式 |
| `globalContext?` | `Record<string, unknown>` | 全局上下文：提供给条件表达式（visibleWhen/editableWhen）取值 |

**Events**:

| 事件 | 载荷 | 说明 |
|------|------|------|
| `module-loaded` | `{ moduleId }` | Schema 加载完成 |
| `view-mode-change` | `{ mode }` | 视图模式切换 |
| `data-changed` | `{ moduleId }` | 数据变更 |
| `error` | `{ moduleId, code, message }` | 加载/运行时错误 |
| `request-open-dialog` | `{ dialogType, payload }` | 打开弹窗请求 |

**defineExpose**:

| 方法 | 说明 |
|------|------|
| `refresh()` | 重新加载模块 |
| `setViewMode(mode)` | 切换视图模式 |
| `getCurrentRecord()` | 获取当前卡片的记录 |
| `undo()` / `redo()` | 撤销/重做一个用户动作（docs/19 H3 引擎级 history） |
| `canUndo` / `canRedo` | ComputedRef，撤销/重做可用性 |

**核心流程**:

```
onMounted → useSchema.loadModule(moduleId)
  → schemaService + userViewConfigService 并行加载
    → schemaMeta 写入 → isLoaded = true → 渲染 ViewContainer

ListView mount → watch filters/sort/page 变化 → fetchData()
  → recordService.list() → recordStore.setRecords()

模式切换 → handleViewModeChange(mode)
  → uiState.setViewMode(mode) → ViewContainer 切换显示
```

**状态机制**:
- **加载成功** → `isLoaded=true` → `ViewContainer` 渲染
- **加载失败** → `loadError` → `<el-empty>` + 重试
- **无权限** → `!canView` → 无权限提示

**工具栏**: 根据 `viewMode` 动态显示：
- list 模式：标题 +（可选）“编辑”按钮 + 列设置按钮 + 列表/卡片/新增切换按钮 + 公式循环警告
- card 模式：标题 + 卡片设置按钮 + 视图切换按钮
- create 模式：标题 + 列表新增/卡片新增切换 + 返回列表按钮

**新增模式双态**: 通过 `currentCreateMode` ref 切换 `CreateView`（列表式批量新增）和 `CardCreateView`（单卡录入）。

**RelationEditor 集成**: 表格中点击关联列时，弹出 RelationEditor 面板直接编辑关联数据。

## 2. ViewContainer（布局容器）

**文件**: `src/engine/containers/ViewContainer.vue`

根据 `viewMode` 切换三个具名 slot：`#list-view` / `#card-view` / `#create-view`。提供 `#toolbar` 和 `#pagination` slot。

**Props**: `schema`, `viewMode`, `records`, `queryState`, `viewConfig`, `loading`

## 3. ListView（列表视图）

**文件**: `src/engine/containers/ListView.vue`

表格模式主视图。编排筛选栏、操作栏、表格、分页、底部标签。

**列表编辑交互（schema.listEditMode）**：
- `inline-dblclick`（默认）：双击单元格进入行内编辑
- `select-then-edit`：单击行高亮选择；禁用双击行内编辑；点击右上角“编辑”切换到卡片视图并自动进入编辑态（基于 selectedRowIds[0]）

**Props**:

| Prop | 类型 | 说明 |
|------|------|------|
| `schema` | `ModuleSchema` | 模块 Schema |
| `viewConfig` | `ColumnConfig[]` | 列配置 |
| `initialQueryState?` | `Partial<QueryState>` | 初始查询状态 |
| `infiniteScroll?` | `boolean` | 无限滚动模式 |

**Events**: `cell-edit`, `query-change`, `open-quick-create`, `formula-detail-open`, `row-action`, `open-relation-editor`, `batch-patch`（docs/19 H4 宿主执行契约，`operations.batchPatch.enabled` 时批量编辑上抛 `BatchPatchEvent`）

**数据获取**: `watch([currentPage, pageSize, filters, currentSort], () => fetchData(), { immediate: true })`，每次参数变化自动查询。

**异步竞态保护**: `fetchData()` 内部检查 `queryModuleId !== loadingModuleId.value`，防止旧异步返回覆盖新模块数据。

**底部 Tab 筛选**:
- 从 Schema 中找第一个 `filterable + select` 字段生成标签
- "全部(N)" + 各选项值及统计数
- 与 SchemaFilterBar 状态联动

**筛选/排序状态栏**: 显示当前激活的筛选条件摘要和排序字段，支持一键清除。

## 4. CardView（卡片浏览视图）

**文件**: `src/engine/containers/CardView.vue`

卡片模式主视图。单卡片浏览 + 上/下条导航 + 分页。

**Props**: `editable`, `cardLayout`, `autoEdit`

**Events**: `field-change`, `save`, `cancel`, `navigate`, `pageChange`

**结构**:
- 上/下条按钮 + 记录数显示（"记录 3/5（共 50 条）"）
- SchemaCard 渲染当前记录
- 分页器

`currentIndex` ref 控制当前卡片索引。若 recordStore.currentRecord 存在且位于当前 records 内，将自动定位到该记录索引；navigate 事件携带 direction 和 index。

## 5. CreateView（列表式批量新增）

**文件**: `src/engine/containers/CreateView.vue`

列表式多行录入视图。支持列锁定（批量填充）、公式自动计算、多选删除、聚合行。

**Props**: `submitting`

**Events**: `save`, `save-and-continue`, `cancel`, `draft-change`, `lock-column`

**核心功能**:

**多行管理**: `addRow()` / `removeRow(index)` / `batchDelete()`
- `addRow()` 时自动应用 locked 列的前一行值
- 新增行后调用 `lifecycle.applyDefaults()` + `lifecycle.evaluateFormulas()`

**列锁定**（批量填充）: `toggleLock(fieldKey)`
- 锁定的列不可编辑，新增行自动复制上一行值
- 通过 `fillLockedValues()` 填充所有空值

**公式展示**: `showFormulaChain` 切换显示/隐藏公式计算链

**聚合行**: 通过 `useDraftLifecycle.computeAggregations()` 计算 sum/average/count/max/min

**列设置**: 复用 `ColumnSettingsPopover`，`columnConfigs` 本地 ref 管理

**多选操作**: 全选/单选/批量删除，状态通过 `selectedIds` Set 管理

**FK 标签解析**: `resolveFkLabel()` 异步获取 FK 字段的显示名

## 6. CardCreateView（卡片式单条新增）

**文件**: `src/engine/containers/CardCreateView.vue`

单卡片录入视图。一个草稿行，16列 Grid 布局展示所有可编辑字段。

**Props**: `submitting`

**Events**: `save`, `cancel`, `draft-change`

**结构**:
- 卡片标题："新建{模块名称}记录"
- 公式展开/收起 toggle
- Grid 布局字段（card-create-grid）
- 底部固定工具栏（取消 + 保存）

`onMounted` 时自动初始化一个草稿行，应用默认值和公式。

## 7. GlobalDialogHost（全局弹窗宿主）

**文件**: `src/engine/dialogs/GlobalDialogHost.vue`

统一管理所有全局弹窗。根据 `uiState.dialogType` 渲染对应弹窗组件。

**支持的弹窗类型**:

| dialogType | 组件 | 说明 |
|------------|------|------|
| `quick-create` | QuickCreateDialog | 快速创建关联记录 |
| `dynamic-max-confirm` | DynamicMaxConfirmDialog | 动态最大值超限确认 |
| `formula-detail` | FormulaDetailPopover | 公式计算链详情 |
| `version-conflict` | ElDialog | 版本冲突提示 |
| `confirm` / `alert` | ElDialog | 通用确认/提示 |

## 8. SchemaContextProvider（依赖注入）

**文件**: `src/engine/providers/SchemaContextProvider.vue`

- `schema`, `viewConfig`, `permissions`
- `records`, `queryState`
- `isSchemaLoading`, `isRecordsLoading`
- `viewMode`
- `loadModule`, `setViewMode`

**Props**: `moduleId`, `initialViewMode?`

使用 `<slot />` 透传子组件。

## 9. RuntimeContext（全局上下文传入规范）

**目的**：为 Schema 中的条件表达式提供「模块外」的全局数据来源，例如系统设置、当前登录用户、权限表、业务开关等。

**传入方式**：通过 `SchemaEngine` 的 `globalContext` prop 传入任意 JSON 对象。

```ts
<SchemaEngine
  module-id="module-voucher"
  :global-context="{
    settings: { defaultCurrency: 'CNY' },
    user: { id: 'u-001', roles: ['finance'] },
    permissions: { canEditExchangeRate: true }
  }"
/>
```

**读取方式**：
- Schema 条件表达式通过 `{ global: 'path.to.value' }` 读取（点路径）
- 引擎内部通过 `useRuntimeContext().global` 获得同一份 globalContext

**规范建议**：
- **稳定键空间**：建议统一放在 `settings` / `user` / `permissions` 顶层，避免散落
- **可序列化**：只放可 JSON 序列化的数据（避免函数、Date、类实例）
- **只读语义**：globalContext 仅用于条件判定，不应被组件写回修改

## 10. QuickCreateDialog（快速创建弹窗）

**文件**: `src/engine/dialogs/QuickCreateDialog.vue`

FK 字段无匹配时的快速创建入口。根据 `targetModuleId` 加载目标 Schema，渲染表单字段。

**Props**: `visible`, `targetModuleId`, `prefillData?`

**Events**: `update:visible`, `created: { id, label, value }`, `cancel`, `close`

## 11. DynamicMaxConfirmDialog（动态最大值确认）

**文件**: `src/engine/dialogs/DynamicMaxConfirmDialog.vue`

动态最大值超限时的软确认弹窗。展示当前值/最大值/比例关系，用户确认或取消。
