# 状态管理

全部使用 Pinia 3 Composition API 风格（`defineStore` + `setup` 函数）。

## 1. schemaMetaStore

**文件**: `src/stores/schemaMetaStore.ts`

模块 Schema 和视图配置的真源。

| State | 类型 | 说明 |
|-------|------|------|
| `schema` | `ModuleSchema \| null` | 当前模块 Schema |
| `viewConfig` | `UserViewConfig \| null` | 用户视图配置（列设置、卡片布局） |
| `permissions` | `ModulePermissions \| null` | 模块权限 |
| `isLoading` | `boolean` | 加载中 |
| `loadError` | `string \| null` | 加载错误信息 |

**Computed**:

| Computed | 说明 |
|----------|------|
| `isLoaded` | `schema !== null` |
| `visibleFields` | 过滤 visible + 权限 + 按 order 排序 |
| `fieldMap` | `Map<string, FieldSchema>`，快速按 key 查字段 |

**Methods**:

| 方法 | 说明 |
|------|------|
| `getField(key)` | 按 key 获取 FieldSchema |
| `getFieldPermission(key)` | 按 key 获取 FieldPermission |
| `setSchema(s)` | 写入 Schema，清除错误 |
| `setViewConfig(c)` | 写入视图配置 |
| `setPermissions(p)` | 写入权限 |
| `setLoading(s)` | 设置加载状态 |
| `setError(e)` | 设置错误信息 |
| `$reset()` | 重置所有状态 |

## 2. recordStore

**文件**: `src/stores/recordStore.ts`

记录数据和草稿的真源。

| State | 类型 | 说明 |
|-------|------|------|
| `records` | `RecordEntity[]` | 当前列表数据 |
| `currentRecord` | `RecordEntity \| null` | 当前卡片记录 |
| `draftRows` | `DraftRecord[]` | 新增草稿行 |
| `undoStack` | `UndoEntry[]` | 撤销栈（最大 50） |
| `queryState` | `QueryState` | 查询状态（filters/sort/pagination） |
| `isLoading` | `boolean` | 数据加载中 |
| `isSaving` | `boolean` | 保存中 |
| `saveError` | `string \| null` | 保存错误 |

**Computed**:

| Computed | 说明 |
|----------|------|
| `totalRecords` | 从 queryState.pagination.total 取 |
| `hasRecords` | records.length > 0 |
| `hasDrafts` | draftRows.length > 0 |
| `currentPage` | queryState.pagination.page |

**关键 Methods**:

| 方法 | 说明 |
|------|------|
| `setRecords(records, total)` | 设置列表数据 |
| `setCurrentRecord(record)` | 设置当前卡片记录 |
| `setQueryState(state)` | 部分更新查询状态 |
| `setPagination(p)` | 部分更新分页 |
| `getRecordById(id)` | 按 ID 查记录 |
| `updateRecordField(id, field, value, newVersion)` | 更新单字段（同时更新 currentRecord） |
| `pushUndo(entry)` | 压入撤销栈 |
| `popUndo()` | 弹出撤销栈 |
| `clearUndo()` | 清空撤销栈 |
| `setDraftRows(rows)` | 替换草稿行 |
| `updateDraftField(index, field, value)` | 更新草稿行字段 |
| `addDraftRow(draft)` | 新增草稿行，返回 index |
| `removeDraftRow(index)` | 删除草稿行 |
| `clearDrafts()` | 清空草稿 |
| `setErrorsForDraft(index, errors)` | 设置草稿行校验错误 |
| `setLoading(s)` | 设置加载中 |
| `setSaving(s)` | 设置保存中 |
| `setSaveError(e)` | 设置保存错误 |
| `$reset()` | 重置所有状态 |

**撤销栈机制**:
- `pushUndo` 入栈，超过 50 条时 shift 最早记录
- `popUndo` 出栈，返回 `UndoEntry`（type/recordId/field/previousValue/timestamp）
- `useCellEdit.onCellEdit` 在编辑前 push，编辑失败时可通过 `undo()` 恢复

## 4. runtimeCacheStore

**文件**: `src/stores/runtimeCacheStore.ts`

运行时缓存，存储候选值、公式结果等临时数据，模块切换时随 `$reset()` 清空。

| State | 类型 | 说明 |
|-------|------|------|
| `candidateCache` | `Map<string, CandidateOption[]>` | FK 候选值缓存 |
| `formulaResultCache` | `Map<string, FormulaResult>` | 公式结果缓存 |

## 状态隔离原则

- **records** vs **drafts**：正式记录和草稿完全隔离，草稿操作不污染正式数据
- **queryState** 唯一真源：filters / sort / pagination 只在一个地方维护
- **dialogState** 唯一真源：全局弹窗状态由 uiState 统一管理
- 模块切换时 `$reset()` 全部 Store，防止旧数据泄露
