# 生命周期与钩子

## 一、完整生命周期流程图

```
SchemaEngine mount
  │
  ├─ onMounted → loadModule(moduleId)
  │    ├─ schemaService.loadModuleSchema()    ← 可介入: 自定义 schemaService
  │    ├─ schemaService.loadModulePermissions()
  │    ├─ userViewConfigService.load()
  │    └─ schemaMeta.setSchema() / setPermissions() / setViewConfig()
  │         │
  │         ▼
  │    result: schemaMeta.isLoaded = true
  │
  ├─ ListView mount
  │    │
  │    ├─ watch(immediate) → fetchData()
  │    │    └─ recordService.list()           ← 可介入: 自定义 recordService
  │    │         └─ recordStore.setRecords()
  │    │
  │    └─ 渲染 SchemaTable
  │         ├─ 列设置管理 (ColumnSettingsPopover)
  │         │    └─ @save → handleColumnSettingsSave → viewConfig 持久化
  │         ├─ 筛选 (SchemaFilterBar)
  │         │    └─ @search → filters → fetchData()
  │         ├─ 排序 (表头点击)
  │         │    └─ @sort-change → currentSort → fetchData()
  │         ├─ 翻页 (SchemaPagination)
  │         │    └─ @page-change → currentPage → fetchData()
  │         ├─ 单元格编辑 → @cell-edit → SchemaEngine
  │         │    └─ cellEdit.onCellEdit()      ← useCellEdit 钩子
  │         ├─ 行操作 → @row-action → SchemaEngine
  │         ├─ 关联列点击 → RelationEditor
  │         └─ 底部 tab 筛选 → @tab-change → filters → fetchData()
  │
  ├─ 列设置保存
  │    └─ handleColumnSettingsSave
  │         └─ schemaMeta.setViewConfig()     ← 可介入: 自定义保存逻辑
  │
  ├─ 模式切换
  │    ├─ "新增" → handleViewModeChange('create')
  │    │    └─ uiState.setViewMode('create')
  │    │         → ViewContainer 显示 CreateView / CardCreateView
  │    │            ├─ addRow() / initializeDraft()
  │    │            ├─ lifecycle.applyDefaults → lifecycle.evaluateFormulas
  │    │            └─ 保存 → handleCreateSave → 切回 list
  │    │
  │    └─ "列表" / "卡片" → handleViewModeChange('list'/'card')
  │
  └─ refresh (defineExpose)
       └─ schema.loadModule(moduleId)          ← 外部刷新入口
```

## 二、阶段一：组件挂载 & Schema 加载

**入口**: `SchemaEngine.vue` `onMounted`

**核心逻辑** (`useSchema.loadModule`):
```typescript
const [schemaRes, permRes, configRes] = await Promise.all([
  schemaService.loadModuleSchema(moduleId),       // Schema 定义
  schemaService.loadModulePermissions(moduleId),  // 权限
  userViewConfigService.load(moduleId),           // 用户配置
])
```

**加载完成后的状态机**:
- **成功** → `schemaMeta.isLoaded = true` → `ViewContainer` 渲染
- **失败** → `schemaMeta.loadError` → `<el-empty>` + 重试
- **无权限** → `!permission.canView` → 无权限提示

## 三、阶段二：数据获取

**入口**: `ListView.vue`

```typescript
watch([currentPage, pageSize, filters, currentSort], () => {
  fetchData()
}, { immediate: true })
```

**参数链**:
```
用户操作(筛选/排序/翻页)
  → filters / currentSort / currentPage 变化
    → watch 触发 fetchData()
      → recordService.list(params)
        → recordStore.setRecords()
          → aggregationSummary computed 重算
            → 模板重新渲染
```

**竞态保护**: `fetchData()` 内部检查 `queryModuleId !== loadingModuleId.value`，模块切换时旧异步返回被丢弃。

## 四、阶段三：渲染阶段

```
ViewContainer (布局容器)
  ├─ #toolbar → 标题 + 列设置/卡片布局按钮 + 模式切换
  ├─ #list-view → ListView
  │    ├─ SchemaFilterBar (筛选栏)
  │    ├─ ListActionBar (列表级操作)
  │    ├─ SchemaTable (vxe-table)
  │    ├─ SchemaPagination (分页器)
  │    └─ BottomTabs (底部 Tab 筛选)
  ├─ #card-view → CardView
  │    └─ SchemaCard + CardGridField (16列 Grid)
  └─ #create-view → CreateView (批量) / CardCreateView (单卡)
```

## 五、交互 → 数据变更回路

### 5.1 单元格编辑回路
```
用户编辑单元格
  → VxeTableWrapper @inline-edit → SchemaTable @cell-edit
    → ListView @cell-edit → SchemaEngine handleCellEdit
      → cellEdit.onCellEdit(payload)
        → recordService.patchField → updateRecordField
          → history.pushCellEdit（成功后入栈,docs/19 H3）
            → emit('data-changed')
```

### 5.2 行操作
```
用户点击行操作按钮
  → VxeTableWrapper @row-action → SchemaTable @row-action
    → ListView @row-action → SchemaEngine handleRowAction
      → ElMessage.info
```

### 5.3 模式切换
```
用户点击"新增"
  → SchemaEngine handleViewModeChange('create')
    → useSchema.setViewMode('create')
      → uiState.setViewMode('create')
        → ViewContainer 切换显示 create-view slot
```

## 六、CreateView 草稿生命周期

```
进入 create 模式
  → recordStore.clearDrafts()                     // 清空旧草稿
  → addRow() / initializeDraft()                  // 初始化草稿行
    → lifecycle.applyDefaults()                   // 填充默认值
    → lifecycle.evaluateFormulas()                // 计算公式

用户编辑字段
  → handleFieldUpdate(index, key, value)
    → recordStore.updateDraftField()              // 更新字段值
    → lifecycle.evaluateFormulas()                // 重算受影响公式
    → emit('draft-change')

用户保存
  → handleCreateSave()
    → formula.evaluateAllFormulas()               // 最终公式计算
    → recordStore.clearDrafts()
    → handleViewModeChange('list')
    → emit('data-changed')
```

## 七、列设置持久化流程

```
ColumnSettingsPopover @save
  → handleColumnSettingsSave(columns)
    → schemaMeta.setViewConfig({ ...columns })
      → columnConfig 变化
        → displayFields computed 重算
          → 表格重渲染（列显隐/排序/宽度）
```

## 九、关键数据流

```
Schema 加载数据流:
  schemaService.loadModuleSchema()
    → schemaMeta.setSchema()
      → visibleFields computed (visible + 权限过滤 + order 排序)
        → displayFields computed (列设置过滤 + 排序)

数据查询数据流:
  recordService.list()
    → recordStore.setRecords()
      → aggregationSummary computed (useAggregation)
        → 底部聚合栏渲染

草稿数据流:
  handleFieldUpdate()
    → recordStore.updateDraftField()
      → lifecycle.evaluateFormulas()
        → formula.evaluateAllFormulas()
          → topologicalSort + safeEval (mathjs)
            → 结果写回 recordStore → 界面自动更新

撤销数据流(docs/19 H3 引擎级 history):
  入栈: cell-edit 成功后 pushCellEdit / 批量编辑 pushBatchEdit(整批一条) / 创建 pushCreate
  撤销: undo() → popUndo → 本地回放(previousValue/previousVersion;create 移出列表) → pushRedo
  重做: redo() → popRedo → 正向重放(newValue/newVersion;create 按位加回) → pushUndo
  新动作入栈清空 redo 栈;回放为本地内存操作,刷新后以服务端数据为准
```
