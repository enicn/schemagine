# 路由与模块

## 路由配置

**文件**: `src/router/index.ts`

使用 `createWebHistory` 模式。

```typescript
const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    { path: '/', redirect: '/voucher' },
    // 快捷模块路由（9个预设模块）
    ...moduleRoutes.map(r => ({
      path: r.path,
      name: r.name,
      component: ModuleDemo,
      props: { moduleId: r.moduleId },
    })),
    // 通用模块路由
    { path: '/module/:moduleId', component: ModuleDemo },
    // Schema 编辑器
    { path: '/editor', component: SchemaEditor },
  ],
})
```

## 模块详情

### module-voucher（凭证管理）
完整功能演示模块。10+ 字段，含公式字段（含税金额 = 金额 × 1.06）、FK 关联（部门）、日期、状态等。E2E 测试主目标模块。

### module-ap（应付账款）
多模块示例。含 FK 关联到供应商、关联凭证，演示跨模块数据关联；默认启用 `listEditMode=select-then-edit` 作为“列表选中后点击编辑跳转卡片”的示例模块。

### module-invoice / module-sales-order / module-receivable / module-user / module-workshop
扩展模块路由，支持通过 URL 快捷访问。

### module-empty
无记录的空模块，测试空态渲染。

### module-no-perm
权限 `view: false`，测试无权限 UI 表现。

## ModuleDemo 视图

**文件**: `src/views/ModuleDemo.vue`

页面级组件，接收 `moduleId` prop 或从 `route.params.moduleId` 读取，直接渲染 `<SchemaEngine>`。

## 模块加载机制

`useSchema.loadModule(moduleId)` 内部：

1. 设置 `loadingModuleId` 作为竞态标识
2. `$reset()` 所有 Store
3. `Promise.all` 并行加载 Schema + Permissions + ViewConfig
4. 每次异步返回检查 `loadingModuleId`，不匹配则丢弃
5. 成功 → `schemaMeta.setSchema/setPermissions/setViewConfig`
6. 失败 → `schemaMeta.setError`
7. 配置加载失败不阻塞，使用 `createDefaultConfig()` 生成默认配置

`createDefaultConfig` 生成包含所有可见字段的默认列配置。

## 模块注册

模块 Schema 在 Mock 层 `sampleSchemas.ts` 中定义。新增模块只需：

1. 在 `sampleSchemas.ts` 添加模块 Schema
2. 在 `sampleRecords.ts` 添加种子数据（可选）
3. 如需快捷路由，在 `router/index.ts` 的 `moduleRoutes` 中添加条目
4. 通用路由 `/module/:moduleId` 可动态加载任意模块 ID
