# Schema 引擎 (Schemagine)

Schema-driven 动态表单与数据管理引擎。基于 Vue 3 + Pinia + Element Plus + vxe-table 构建，支持通过 Schema 配置动态渲染列表、卡片、新增三种视图。

## 技术栈

| 层 | 技术 |
|---|------|
| 框架 | Vue 3.5 (Composition API + `<script setup>`) + TypeScript 6 |
| 构建 | Vite 8 |
| 状态管理 | Pinia 3 |
| UI 组件 | Element Plus 2.13 |
| 表格 | vxe-table 4.18 + vxe-pc-ui 4.13 |
| 路由 | vue-router 5 |
| 公式引擎 | mathjs 15 |
| 测试 | Vitest 4 + Playwright 1.59 |
| Lint | ESLint 10 + oxlint 1.60 |
| 包管理 | pnpm |

## 架构速览

```
SchemaEngine (入口)                 ← 加载 Schema、权限、用户配置，编排全局流程
  └─ SchemaContextProvider          ← provide 上下文 (schema/records/viewMode/...)
       └─ ViewContainer             ← 布局容器，根据 viewMode 切换子视图
            ├─ ListView             ← 列表视图（表格模式）
            │    ├─ 表头筛选/排序弹层 ← 每列表头箭头按钮：升序/降序/清除排序 + 内容筛选（候选值+计数）
            │    ├─ ListActionBar   ← 列表级操作按钮
            │    ├─ SchemaTable     ← vxe-table 表格
            │    └─ .list-footer    ← 底部栏（BottomTabs + 分隔线 + SchemaPagination）
            ├─ CardView             ← 卡片浏览视图（上/下条导航）
            │    └─ SchemaCard      ← 单卡片渲染（16列Grid布局）
            └─ CreateView / CardCreateView ← 新增视图（批量/单卡片录入）
```

数据流：`UI → Store/Composables → Service/Mock` （严格单向）

## 列表编辑模式（listEditMode）

Schema 支持配置列表视图的编辑交互模式（`ModuleSchema.listEditMode`）：

```json
{
  "id": "module-ap",
  "listEditMode": "select-then-edit"
}
```

- `inline-dblclick`（默认）：双击单元格进入行内编辑
- `select-then-edit`：单击行高亮选择；点击右上角“编辑”切换到卡片视图并进入编辑态

该配置也可在 Schema 编辑器的「模块配置 → 列表编辑模式」中修改。
