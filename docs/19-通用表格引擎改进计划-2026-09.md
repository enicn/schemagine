## 二、批次 A(专项):Schema Playground —— Schema 结构文档演示工具

> **状态:✅ 已完成(2026-09-15)。** 交付 A1–A7 全部内容:`src/schemaMeta/`(51+14 项元数据 + 穷举键表防漏)、`/playground` 三区布局(结构树 / 配置项文档·可视化编辑 / 实时预览+反查)、示例值一键应用、模板选择、`pnpm gen:schema-docs` 附录再生成;附带修复引擎 bug:SchemaTable 列构建未传递 `decimal/decimalMode/maxDecimal`。验收:单测 198/198(新增 77)、type-check 0 错误、lint 0 errors、浏览器实测编辑→保存→预览联动通过。

### A-1 定位

与现有 `/editor`(SchemaEditor,生产向:经 `schemaService` 读写持久化模块)区分,**Playground 是文档 + 演示工具**:

- **了解配置项、属性值**是一等公民:每个 `ModuleSchema`/`FieldSchema` 属性都有说明、类型、默认值、取值枚举、适用字段类型、生效面(渲染 / 行内编辑 / 筛选 / 表单 / 卡片)、引入版本与示例值;
- **可视化编辑**:补齐现有 `FieldSchemaFormPanel` 的覆盖缺口(当前仅覆盖约 22/50 属性,且无任何属性说明),全部属性由元数据驱动生成表单控件;
- **实时效果联动**:预览即引擎本体(embedded `SchemaEngine`),改属性立即看到效果;支持从预览反查属性;
- **沙箱隔离**:不落库、不污染 localStorage(A 阶段复用 `SchemaPreview` 的 `preview-<id>` mock 通道;批次 C1 落地后切换为内存本地数据源)。

### A-2 核心设计:属性元数据注册表(单一事实来源)

新增 `src/schemaMeta/` 目录,声明式描述全部配置项。文档表格、编辑表单、示例值、Markdown 导出全部由它驱动,避免"文档滞后于代码"(仓库既有教训):

```ts
// src/schemaMeta/types.ts(示意)
export interface PropertyMeta {
  /** 如 'FieldSchema.decimal'、'ModuleSchema.listEditMode' */
  path: string
  label: string                 // 中文显示名
  appliesTo: FieldType[] | 'all'
  kind: 'string' | 'number' | 'boolean' | 'enum' | 'array' | 'object' | 'condition'
  enumValues?: { value: string; label: string; desc?: string }[]
  default?: unknown
  required?: boolean
  since?: string                // 引入版本,如 '2.0'
  /** 生效面:渲染 / 行内编辑 / 筛选 / 新建表单 / 卡片 */
  surfaces: Array<'render' | 'inline-edit' | 'filter' | 'form' | 'card'>
  description: string
  example?: unknown             // 示例值,支持一键应用
  related?: string[]            // 关联属性,如 decimal → [decimalMode, maxDecimal]
}
```

文件划分:`types.ts`(接口)、`moduleMeta.ts`(ModuleSchema 顶层属性)、`fieldMeta.ts`(FieldSchema 全量属性)、`index.ts`(查询 API:按字段类型过滤 / 关键词搜索 / 按分组与生效面聚合)。

**防漏单测**:反射比对元数据键集合与 `FieldSchema`/`ModuleSchema` 的 TS 字段集合,新增属性漏登记时单测失败。

### A-3 页面结构(三区布局,路由 `/playground`,dev-only)

```
┌──────────┬──────────────────────────────┬─────────────────┐
│ 结构树    │ 属性工作区(两种模式)          │ 实时预览          │
│          │                              │                 │
│ ▾ 模块配置│ [文档模式] 属性文档表格         │ [列表|卡片|新建]  │
│   模块属性│  搜索 / 分组 / 生效面筛选       │                 │
│ ▾ 字段    │  每行:说明·类型·默认值·取值    │  SchemaEngine    │
│   ○ 名称  │ [编辑模式] 元数据驱动表单       │  (embedded)     │
│   ● 金额  │  控件旁带文档 tooltip 与       │                 │
│   ○ 状态  │  「恢复默认值」                 │ ☑ 反查模式       │
└──────────┴──────────────────────────────┴─────────────────┘
```

- **文档模式**:属性表格可搜索、按分组(基础/展示/编辑/筛选/条件与权限/关系/公式)与生效面筛选;任意属性 3 次点击内可达;
- **编辑模式**:控件由 `kind` 生成——enum→下拉、boolean→开关、number→数字框、array/object→结构化编辑器(`ValidationRule[]`、`SelectOption[]`、`RowActionConfig` 行内表格;`Condition` 用条件构建器,复用 `utils/condition.ts` 的算子模型);切换字段类型时按 `appliesTo` 过滤属性;
- **反查模式**:开启后点击预览中的列/单元格,左侧定位到对应字段并高亮其生效属性(渲染属性 → 列外观,如 `decimal/decimalMode` → 数值格式、`statusMap` → 标签颜色);
- **示例值**:每属性带 `example`,一键应用;起步模板直接加载 `sampleSchemas` 9 个示例模块。
