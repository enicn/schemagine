# docs/20 - 外观与格式契约（EngineAppearance）

> 目标：格式/风格类设置项统一收敛为引擎契约，宿主经 SchemaEngine 的 `appearance` prop 控制，
> 提升复用度——宿主不再需要用全局 CSS 覆盖引擎内部类名。
> 设计原则：**未声明 = 与历史渲染完全一致（零声明零变化）**；字段级可覆盖引擎级。

## 1. SchemaEngine.appearance

```ts
import type { EngineAppearance } from 'schemagine'

const appearance: EngineAppearance = {
  tableBorder: 'full',          // 表格边框
  valueDisplay: 'plain',        // 单元格值展示
  cardDensity: 'compact',       // 卡片（详情/编辑）密度
  inlineEditLayout: 'fit-row',  // 行内编辑布局（浮层/行内收纳）
  exportCsvInConservative: true, // 保守工具栏下仍显示导出入口
}

<SchemaEngine module-id="module-x" :appearance="appearance" />
```

| 键 | 取值 | 默认 | 说明 |
|----|------|------|------|
| `tableBorder` | `'full' \| 'inner' \| 'outer' \| 'none'` | `'inner'` | 表格边框档位，透传 vxe-table `border`。`full`=外框+内框+列分隔线（SAP 观感）；`inner`=仅内框线（历史默认）；`outer`=仅外框；`none`=无边框 |
| `valueDisplay` | `'tag' \| 'plain' \| 'classic'` | `'tag'` | 单元格值展示。`tag`=枚举按 `options[].color` 渲染彩色标签、select/fk 非空值渲染 `cell-tag` 胶囊（历史默认）；`plain`=全部降级为普通字色纯文本，统一字体、无底色描边；`classic`=上世纪电子表格风格（严格单色）——在 plain 基础上**忽略字段级 `displayStyle`**，并禁用布尔状态色、`trueLabelClass`/`falseLabelClass` 自定义类与筛选匹配高亮，schema 声明的一切取值染色与自定义样式均不渲染 |
| `cardDensity` | `'default' \| 'compact'` | `'default'` | 卡片视图与新建表单密度。`compact`=普通字段默认跨度 8→4（16 列栅格下每行 2 个→4 个）+ 栅格间距与导航条收紧，详情/编辑/新建一屏化；新建表单去掉宽度上限、满宽利用。窄屏（≤768px）强制一行两个、≤480px 一行一个，字段跨度自动钳制 |
| `exportCsvInConservative` | `boolean` | `false` | `toolbarMode='conservative'` 时仍显示「导出CSV」入口（需同时 `permissions.export` 允许）。对 `toolbarMode='full'` 无影响 |
| `exportExcelInConservative` | `boolean` | `false` | `toolbarMode='conservative'` 时仍显示「导出Excel」入口（需同时 `permissions.export` 允许）。对 `toolbarMode='full'` 无影响 |
| `inlineEditLayout` | `'float' \| 'fit-row'` | `'float'` | 行内编辑（双击单元格）布局，见 §2.6 |

## 2. 字段级覆盖：FieldSchema.displayStyle

```ts
{
  key: 'status',
  type: 'status',
  options: [
    { label: '待审核', value: 'pending', color: '#e6a23c' },
    { label: '已通过', value: 'approved', color: '#67c23a' },
    { label: '已驳回', value: 'rejected', color: '#f56c6c' },
  ],
  displayStyle: 'tag',   // 全局 plain 下保留彩色标签
}
```

- 取值：`'tag' | 'plain'`，仅对 select / multi-select / status / fk 四类值列生效。
- **优先级：字段 `displayStyle` > 引擎 `appearance.valueDisplay` > 默认 `'tag'`**。
- 典型场景：全局 `valueDisplay: 'plain'`（表格风格统一）下，审核状态等关键列声明
  `displayStyle: 'tag'` 保留彩色，避免误操作。
- 已登记 schemaMeta（`FIELD_META.displayStyle`），Schema 编辑器属性行可见；穷举键表
  （`FIELD_SCHEMA_KEYS`）守护新增属性防漏。

## 2.5 卡片头部的 schema 声明动作（type:'action'）

schema 中声明 `type: 'action'` + `rowAction` 的字段，除渲染在列表操作列外，**同时渲染在卡片头部
ID 胶囊一侧**（`SchemaCard`），`rowAction.visibleWhen` 按当前记录逐条求值，`rowAction.danger` 标红。
点击经 `row-action` 事件上抛宿主（payload `{ rowId, field, actionId }`，与列表操作列同构），
由宿主决定执行语义（如凭据「审核」= 直接审核通过并生成银行流水）。卡片处于编辑态时按钮禁用。
翻页器也移入卡片头部中槽（`header-center`），利用头部空白提升紧凑度。

## 2.6 行内编辑布局：appearance.inlineEditLayout

列表双击单元格进入行内编辑时，编辑器（输入控件 + 确认/取消按钮）的摆放方式：

| 档位 | 形态 | 适用 |
|------|------|------|
| `'float'`（默认） | 浮层——编辑器绝对定位浮于相邻行之上，确认/取消在编辑框下一排，宽列时输入与按钮并排、窄列自动换行。仅编辑中单元格放开溢出裁剪（见下），配合滚动入视口/翻转逻辑 | 常规场景，编辑空间大 |
| `'fit-row'` | 行内收纳——输入控件与确认/取消**同排**压缩进固定行高（default 密度 44px 下编辑器高 32px），不超出行、不遮挡相邻行；media 编辑改横排、缩略图收进行高 | 宿主容器对溢出裁剪严格、或浮层形态干扰相邻行阅读 |

**为什么需要这个开关（溢出裁剪的来龙去脉）**：数据行默认 `overflow: hidden` 不是引擎显式设置的样式，
而是 vxe-table 的内置约束——密度档经 `cell-config.height` 配置固定行高后，vxe 给所有数据 td 挂
`col--cs-height` 类并内置 `overflow: hidden`，保证固定行高不被高内容撑破（虚拟滚动的行高几何同样
依赖它）；`show-overflow: 'title'` 另给单元格挂 `col--ellipsis` 实现单行省略。两者是查看态必要的
基线，不能全局移除。浮层编辑器高出行高，历史上依赖「编辑态单元格逐层放开裁剪」的覆盖样式显示，
但该覆盖此前漏掉了 td 这一层，确认/取消按钮被 td 底边裁掉（docs/19 F1 密度落地后显现）。
现引擎已补齐 td 层放开（仅编辑中单元格，查看态约束不变）；`fit-row` 档则完全不依赖浮层溢出，
作为裁剪严格环境下的兼容布局。

## 3. card-actions 插槽（宿主业务动作注入卡片头）

卡片视图头部（标题 + 状态标签 + 编辑/保存/取消）预留宿主动作注入点，插槽透传链：

```
SchemaEngine (#card-actions) → CardView (#extra-actions) → SchemaCard (#extra-actions)；另有 schema 声明通道见 §2.5
```

```vue
<SchemaEngine ref="engineRef" module-id="module-voucher" :appearance="appearance">
  <template #card-actions="{ record, editing }">
    <ElButton
      v-if="canApprove && record?.fields?.status === 'pending' && !editing"
      type="primary" size="small"
      @click="approve(record)"
    >审核通过</ElButton>
  </template>
</SchemaEngine>
```

作用域参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `record` | `RecordEntity` | 卡片当前记录（响应式，随上一页/下一页导航更新） |
| `editing` | `boolean` | 卡片是否处于整卡编辑态（编辑中可据此禁用业务动作） |

## 4. 生效范围与边界

- `valueDisplay: 'plain'` 仅作用于**列表单元格展示路径**（非编辑态、非筛选面板、非卡片视图）；
  行内编辑、表单编辑器、筛选器 UI 不受影响。
- boolean 列的 `trueLabelClass/falseLabelClass` 通道独立于 `valueDisplay`，不随之降级。
- `tableBorder` 透传 vxe-table，深浅色主题下的边框颜色由 vxe 主题变量决定。
- `cardDensity: 'compact'` 只改默认布局；用户已保存的卡片自定义布局
  （UserViewConfig.cardLayout）优先于默认值。
